# Lumina CRM v3.3.0 修复与产品增强计划

- 日期：2026-07-29
- 输入：`AUDIT_2026-07-29_V3.3.0.md`
- 目标版本：3.3.0
- 状态：已完成

## 1. 完成定义

1. 审计中的 P1/P2/P3 仓库内缺口全部关闭，不以按钮禁用或文档建议替代数据层约束。
2. 同一新会话请求键和同一规范化负载只创建一次；同键异负载返回稳定冲突。
3. 同一已成功消息请求重放不再次调用供应商；并发/短时重放只有一个投递所有者。
4. 收件箱只加载当前页摘要，准确返回总数；单个会话的消息历史单独分页。
5. 搜索、会话页码、消息页码和选中会话在写后刷新中保持一致。
6. 新迁移有序、可校验并能在本地 PostgreSQL 前向应用。
7. 定向契约、数据库 smoke、类型检查、lint、一次最终生产 build 和直接相关
   Chromium 1228 阶段通过。
8. 最终逐项复查本计划遗漏，更新版本/状态资料并提交。

- [x] 保留显式失败重试、联系人同意/限制检查、稳定供应商幂等键和超时边界。
- [x] 新增路由与数据库契约，证明成功重放不产生外部副作用。

### WP-3：分页收件箱与消息历史

- [x] Repository 拆分收件箱页与会话详情类型，不再返回所有会话的全部消息。
- [x] API 校验会话页、消息页和每页数量，并保持搜索限制。
