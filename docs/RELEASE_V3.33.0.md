# v3.33.0 — Operational usability and dependable recovery

Students can be added directly from the Student workspace, and parents from their Family. Linking an existing person remains optional. Institution contacts stay in their own directory, with an Institution head classification.

New native business records receive automatic numbers using product and organization English initials, an increasing sequence and the workspace date. Missing context uses the record-kind fallback. Historical numbers and explicit imported identifiers remain unchanged; allocation safely skips occupied identifiers.

Admissions templates include editable Institution application and Course / program enrollment presets. Product creation can copy descriptions and billing settings into a new draft while requiring a new price decision. CSV/XLSX import headers follow the selected Chinese or English language and retain stable import keys.

The opportunity Pipeline and list now share archived-subject visibility. Management overview handles an empty channel result without rejecting the whole report. Trend charts, clearer business-domain colors, aligned duplicate selectors, shared account pagination, improved agreement/lead/detail layouts and consolidated assistance navigation make operations easier to scan.

Student and family-person creation preserve the exact request after an uncertain response. Workflow-template saves offer refresh-only recovery after an accepted write. Report errors expose bounded support references and actionable bilingual guidance without exposing source data or SQL.

Apply migrations **121–123** with this runtime. No previous migration is rewritten. The technical number counter is not a financial owner. Contract, Payment, Refund, Receivable, Commission and Revenue accounting ownership remain unchanged. No automatic Revenue recognition/posting, general ledger, tax, provider AP, accounting FX or attribution feature is added.
